# 설비자재 공급 안내 포털 사용법

레미콘 현장에 설비·배관·공구잡자재를 공급하는 설비자재유통팀의 고객 안내 포털입니다. 서버나 설치 없이 `index.html` 파일 하나로 동작합니다.

## 열기

1. 폴더의 `index.html`을 더블클릭하면 브라우저에서 열립니다.
2. 자료실의 파일 다운로드는 `files` 폴더가 `index.html`과 같은 위치에 있어야 동작합니다. 폴더째로 옮기거나 공유하세요.
3. 사내 웹 서버나 공유 폴더에 올릴 때도 `index.html`, `files` 폴더를 함께 올리면 됩니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 포털 본체(화면·계산기·견적 양식·FAQ가 모두 들어 있음) |
| `files/product-catalog.pdf` | 제품 카탈로그 (자료실 목록에서 `설비자재_제품카탈로그.pdf`로 저장됨) |
| `files/order-delivery-guide.pdf` | 주문·납품 거래 안내서 (자료실 목록에서 `주문납품_거래안내서.pdf`로 저장됨) |
| `이전버전/` | 이전 버전 보관 폴더 (`portal-v2.html`은 디자인 적용 전 원본 사본) |
| `README.md` | 이 문서 |

파일명은 한글·공백 없이 영문 소문자와 하이픈으로 씁니다. 새 파일도 같은 규칙으로 이름을 지어 주세요.

## 화면 구성

상단 메뉴로 각 영역으로 이동합니다.

홈 → 취급 품목 → 수량 계산기 → 주문 절차 → 견적 요청 → FAQ → 자료실

- 지금 보고 있는 영역의 메뉴 항목이 초록색으로 강조됩니다. 화면을 내리면 따라 바뀝니다.
- 홈의 캐릭터를 누르면 하트가 올라옵니다.

### 스마트폰 메뉴

- 화면 폭이 760px 이하이면 메뉴가 오른쪽 위 햄버거(≡) 버튼 안으로 접힙니다. 누르면 메뉴가 펼쳐지고 버튼은 ✕로 바뀝니다.
- 메뉴 항목을 누르면 해당 영역으로 이동하면서 메뉴가 자동으로 닫힙니다.
- 메뉴 바깥을 누르거나 키보드 Esc를 눌러도 닫힙니다.
- 펼친 메뉴에서는 현재 영역이 초록색 글자와 오른쪽 점(●)으로 표시됩니다. 항목을 누르면 이동 중에도 누른 항목이 바로 강조됩니다.

## 취급 품목

위쪽 필터(전체 / 설비 / 배관 / 설비자재)를 누르면 해당 분류의 카드만 보입니다. 카드는 설비 3개, 배관 3개, 설비자재 3개입니다. 품목은 취급 분야 예시이며, 세부 규격과 재고는 견적 요청 시 확인해 드립니다.

## 수량 계산기

배관이 몇 본 필요한지와 예상 금액을 바로 계산합니다.

| 입력 | 설명 |
| --- | --- |
| 배관 총 길이 | 필요한 전체 길이(m) |
| 1본 길이 | 배관 1본의 길이(m) |
| 1본 단가 | 공급가(VAT 별도, 원). 비워 두면 본수만 계산합니다 |

결과에는 필요 본수(올림), 공급 총 길이, 여유 길이, 공급가액, 부가세(10%), 예상 금액(VAT 포함)이 나옵니다.

- 예: 총 길이 125 m, 1본 길이 6 m, 단가 35,000원 → 21본, 공급 총 길이 126 m, 여유 길이 1 m, 공급가액 735,000원, 부가세 73,500원, 예상 금액 808,500원
- 길이는 0보다 커야 하고 단가는 0 이상이어야 합니다. 조건에 맞지 않으면 입력 칸 아래에 안내 문구가 나옵니다.
- "초기화"를 누르면 세 칸이 모두 지워집니다.
- 절단 손실(로스)과 여유분은 반영하지 않은 단순 계산값입니다. 실제 견적과 다를 수 있습니다.

## 견적 요청

종이 견적 요청서처럼 직접 입력하는 양식입니다. 이 페이지에서 서버로 전송되지는 않습니다.

1. 업체명, 담당자, 연락처는 반드시 입력합니다. 이메일, 납품 현장, 희망 납품일은 선택입니다.
2. 품목 표에 제품명, 규격, 수량, 단위, 비고를 적습니다. 기본 5행이고 "+ 행 추가"로 늘릴 수 있습니다. 행 오른쪽 ×를 누르면 삭제되고, 마지막 한 행은 삭제되지 않고 내용만 지워집니다.
3. 제품명이 있는 품목이 1개 이상 있어야 합니다. 비어 있으면 안내 문구가 나옵니다.
4. 아래 버튼으로 담당자에게 전달합니다.
   - **양식 내용 복사**: 입력 내용을 글로 복사합니다. 메일이나 메신저에 붙여 넣으세요.
   - **엑셀(CSV) 저장**: 엑셀에서 열 수 있는 CSV 파일로 저장합니다. 파일명은 `견적요청서_업체명.csv` 형태로 자동 생성됩니다.
   - **인쇄 / PDF 저장**: 견적 요청서만 인쇄하거나 PDF로 저장합니다.

## FAQ

검색창에 단어를 입력하면 분류·질문·답변에서 찾아 일치한 항목만 남기고, 일치한 단어를 강조하며 답변을 자동으로 펼칩니다. 검색어를 지우면 처음 상태로 돌아갑니다. 일치하는 항목이 없으면 "검색 결과가 없습니다" 안내가 나옵니다.

## 자료실

`files` 폴더의 자료를 목록으로 보여 줍니다. 한 줄에 파일명, 설명, 용량, "다운로드" 버튼이 표시됩니다.

| 파일명(저장되는 이름) | 설명 | 용량 | 실제 파일 |
| --- | --- | --- | --- |
| 설비자재_제품카탈로그.pdf | 설비·배관 자재 취급 품목과 규격, 인증 기준을 안내합니다. | 264 KB | `files/product-catalog.pdf` |
| 주문납품_거래안내서.pdf | 견적 요청부터 현장 납품까지의 절차와 기준을 안내합니다. | 243 KB | `files/order-delivery-guide.pdf` |

- "다운로드"를 누르면 PDF가 새 창으로 열리지 않고 바로 내려받아지며, 위 표의 한글 파일명으로 저장됩니다.
- 링크는 `files/파일명` 상대 경로입니다. `index.html`과 `files` 폴더를 같은 위치에 두어야 합니다.

### 자료 추가하기

1. 파일을 `files` 폴더에 영문 소문자와 하이픈으로 된 이름으로 넣습니다(예: `files/pipe-spec-sheet.pdf`).
2. `index.html`을 메모장 등으로 열어 `<ul class="files-list">`를 찾고, `<li class="file rv">` 블록 하나를 복사해 아래에 붙여 넣은 뒤 값을 고칩니다.

```html
<li class="file rv">
  <div class="file-main">
    <h3 class="file-name">배관규격표.pdf</h3>
    <p class="file-desc">배관 및 부속류 규격(치수·재질 등)을 정리한 규격표입니다.</p>
  </div>
  <span class="file-size" aria-label="용량 120 KB">120 KB</span>
  <a class="btn btn-white" href="files/pipe-spec-sheet.pdf" download="배관규격표.pdf" aria-label="배관규격표.pdf 다운로드">다운로드</a>
</li>
```

   - `file-name`: 화면에 보이는 파일명(저장되는 이름과 같게 씁니다)
   - `href`: `files/` 뒤에 실제 파일명
   - `download`: 내려받을 때 저장될 이름(한글 가능)
   - 용량: 파일 속성에서 크기를 확인해 KB로 적습니다(1 KB = 1,024바이트, 반올림)
3. 저장한 뒤 브라우저에서 새로고침합니다.

파일을 지울 때는 `files` 폴더의 파일과 `index.html`의 해당 `<li>` 블록을 함께 지워야 합니다.

## 내용 고치기

`index.html` 안에서 해당 부분을 찾아 글을 바꾸고 저장하면 됩니다.

- 취급 품목 카드: `<article class="card"` 로 시작하는 블록
- FAQ: `<details class="faq"` 로 시작하는 블록
- 주문 절차: `<ol class="steps">` 안의 4단계
- 색·글꼴·여백: `<style id="design-system-우리부서포털">` 블록(디자인 시스템 '우리 부서 포털'의 값)
